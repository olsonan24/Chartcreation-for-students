# Aionis Product Planning

1. Apply `.agents/skills/aionis-ai-workflow/SKILL.md` and read only the relevant files from `docs/aionis-operating-system/01-governance-and-non-negotiables.md` through `docs/aionis-operating-system/05-human-approval-gates.md` plus task-specific contracts.
2. Start from `docs/aionis-operating-system/templates/feature-specification.md`.
3. Declare one target, current and expected behavior, in/out scope, protected contracts, build-time/runtime AI, data class, and tenant boundary.
4. Define measurable acceptance evidence, required reviews and gates, analytics, rollback, dependencies, risks, and unknowns requiring Inquiry.
5. Create the implementation plan and file-ownership table. Separate workstreams and write integration contracts for any overlap.
6. Stop at the Plan Gate. Do not interpret a draft plan as approval to build, deploy, change formulas, or change constitutional methodology.
