# Aionis Human Pattern Dream Review

1. Apply `.agents/skills/aionis-ai-workflow/SKILL.md`; read `docs/aionis-operating-system/06-knowledge-and-memory-architecture.md`, `07-evidence-lineage-and-versioning.md`, and `09-human-pattern-dreaming.md` in that directory.
2. Inspect the pattern ledger, dream proposal, generation manifest, and evidence records; use `docs/aionis-operating-system/templates/dream-review.md`.
3. Distinguish user statements, calculations, system inferences, and user-confirmed inferences.
4. Verify supporting and contradictory evidence; reject self-supporting generated conclusions.
5. Require conditional language or Inquiry where resolution is unknown, calibrated confidence/decay, and approval for sensitive conclusions.
6. Verify user and organization isolation, complete versions, supersession, and rollback.
7. Block any automatic global or constitutional methodology change. Return the exact Dream Gate decision and conditions.
