# Complete Implementation Roadmap

This roadmap is sequencing guidance, not authorization. Prompt 1 installs contracts only; no later phase begins automatically.

| Phase | Outcome | Required gate |
| --- | --- | --- |
| 1 | Documentation, schemas, templates, and project-local skills | Plan/Code review of foundation |
| 2 | Repository gap audit against approved contracts | Plan Gate |
| 3 | Shared contract package and deterministic validators | Code Gate |
| 4 | Orchestrator state and artifact handoffs in development tooling | Plan + Code Gates |
| 5 | Evidence lineage and generation-manifest plumbing | Plan + Code Gates |
| 6 | Private backend identity, isolation, and personal evidence store | Plan + Security + Code Gates |
| 7 | Governed runtime synthesis and Inquiry behavior | Intelligence + Security + Code Gates |
| 8 | Operational and product/intelligence analytics | Analytics + Security + Code Gates |
| 9 | Development Dream proposal pipeline | Dream + Code Gates |
| 10 | Human Pattern Dream proposal and profile versioning | Dream + Intelligence + Security Gates |
| 11 | Consented de-identified global learning evaluation | Dream + Intelligence + Security Gates |
| 12 | Staged release, rollback rehearsal, production approval, observation | Release Gate |

Each phase begins with a new feature specification that revalidates assumptions, target boundaries, consent, current architecture, open work, and dependencies. Later phases must not treat draft schemas as deployed services or persistence.

The single next action after Prompt 1 is human review of the draft foundation; do not start the repository gap audit until separately instructed.
