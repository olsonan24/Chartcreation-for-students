# Global Intelligence Learning

## Global-intelligence loop

Analyze consented, de-identified outcomes → evaluate rules and language → produce methodology proposals → conduct formal review → release a governed intelligence version.

Global learning is isolated from personal profile updates. Inputs must have recorded consent, de-identification, cohort thresholds, permitted purpose, retention, and access controls. Outputs must be tested for leakage, bias, confidence calibration, version comparability, and subgroup harm.

Global learning and Dreaming never automatically rewrite constitutional methodology. A methodology proposal must identify the current and proposed rule/language, aggregate evidence, exclusions, limitations, security and intelligence reviews, migration/rollback impact, and Dream Gate decision.

Private user evidence does not become global evidence merely because identifiers were removed. The approved aggregation contract determines eligibility. Small cohorts, rare combinations, free text, and linkable attributes require suppression or rejection.

Release a new governed intelligence version only after formal review and Release Gate approval. Preserve the prior version, evaluation set, decision record, and rollback path.
